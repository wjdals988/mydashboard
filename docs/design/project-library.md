# JM 프로젝트 라이브러리

## 사용자와 목적

직접 만든 웹 서비스와 Android 앱을 방문자가 탐색하고, 실행하거나 설치하고,
구현 범위와 개발 상태를 확인하는 공개 프로젝트 보드다.

## 디자인 계획

- 색: Cloud #F5F7FB, Paper #FFFFFF, Ink #17243A, Cobalt #2458D3,
  Slate #526078, Forest #176C4A. 어두운 테마는 Navy #101827와 Ice #EDF2FA.
- 글꼴: 자체 호스팅 Pretendard Std Variable. 제목 32–64px/650,
  본문 16px/1.75, 부가 정보 13–14px. 숫자에만 tabular-nums 사용.
- 구조: 넓은 소개와 최신 제품 미리보기 → 검색/상태 탭 → 프로젝트 목록 →
  설치 라이브러리. 왼쪽 정렬, 최대 1280px, 모바일 20px 여백.
- 원칙: 프로젝트 화면을 주인공으로 둔다. 실제 상태와 프리뷰/정식 배포를
  구분한다. 실행/설치를 주 동작으로, 기술과 이력은 상세에서 보여 준다.

```text
[JM 작업실]       [프로젝트 / 다운로드]   [테마 / GitHub]
[짧은 소개 + 탐색]                [최근 프로젝트 실제 화면]
[검색________________] [정렬]        [상태 탭 / 추가 필터]
[프로젝트]            [프로젝트]            [프로젝트]
[앱 설치 목록: 상태 + 버전 + 다운로드]
```

## 계획 검토

UI UX Pro Max의 첫 검색은 FAQ 패턴으로 분류되어 사용하지 않았다.
두 번째 검색은 포트폴리오 스타일과 모노크롬/블루 팔레트에 적합했지만,
스크롤 스토리텔링과 Brutalism의 즉각 전환은 이 제품의 탐색과 애니메이션
요구에 맞지 않아 채택하지 않았다. 일반 SaaS 통계 카드와 반복된 영문
라벨도 제거한다. 한국어 자체 호스팅 글꼴과 실제 프로젝트 미리보기,
제품별 실행 동선을 중심으로 다시 구성한다.

## 동작 및 접근성

- 검색/정렬/필터는 URL로 공유하며 상세에서 목록으로 돌아오면 유지한다.
- 모바일 추가 필터는 점진적으로 펼친다. 모든 입력에 보이는 레이블을 둔다.
- 주요 조작은 44px 이상, 키보드 포커스와 결과 수 안내를 제공한다.
- 첫 화면에서 한 번만 진입 애니메이션을 사용한다. 나머지는 사용자가
  조작한 버튼·테마·필터의 피드백에 집중한다.
- prefers-reduced-motion에서는 이동과 애니메이션을 비활성화한다.
- CSS 토큰으로 두 테마를 함께 관리한다. 운영 상태를 색과 텍스트로 표시한다.
