# JM 프로젝트 라이브러리

## 사용자와 목적

직접 만든 웹 서비스와 Android 앱을 방문자가 탐색하고, 실행하거나 설치하고,
구현 범위와 개발 상태를 확인하는 공개 프로젝트 보드다.

## 디자인 계획

- 색: Cloud #F5F7FB, Paper #FFFFFF, Ink #17243A, Cobalt #2458D3,
  Slate #526078, Forest #176C4A. 어두운 테마는 Navy #101827와 Ice #EDF2FA.
- 글꼴: 자체 호스팅 Pretendard Std Variable. 제목 32–64px/650,
  본문 16px/1.75, 부가 정보 13–14px. 숫자에만 tabular-nums 사용.
- 구조: 넓은 소개와 최신 제품 미리보기 → 검색/상태 탭 → 프로젝트 목록 →
  설치 라이브러리. 왼쪽 정렬, 최대 1280px, 모바일 20px 여백.
- 원칙: 프로젝트 화면을 주인공으로 둔다. 실제 상태와 프리뷰/정식 배포를
  구분한다. 실행/설치를 주 동작으로, 기술과 이력은 상세에서 보여 준다.

```text
[JM 작업실]       [프로젝트 / 다운로드]   [테마 / GitHub]
[짧은 소개 + 탐색]                [최근 프로젝트 실제 화면]
[검색________________] [정렬]        [상태 탭 / 추가 필터]
[프로젝트]            [프로젝트]            [프로젝트]
[앱 설치 목록: 상태 + 버전 + 다운로드]
```

## 계획 검토

UI UX Pro Max의 첫 검색은 FAQ 패턴으로 분류되어 사용하지 않았다.
두 번째 검색은 포트폴리오 스타일과 모노크롬/블루 팔레트에 적합했지만,
스크롤 스토리텔링과 Brutalism의 즉각 전환은 이 제품의 탐색과 애니메이션
요구에 맞지 않아 채택하지 않았다. 일반 SaaS 통계 카드와 반복된 영문
라벨도 제거한다. 한국어 자체 호스팅 글꼴과 실제 프로젝트 미리보기,
제품별 실행 동선을 중심으로 다시 구성한다.

## 동작 및 접근성

- 검색/정렬/필터는 URL로 공유하며 상세에서 목록으로 돌아오면 유지한다.
- 모바일 추가 필터는 점진적으로 펼친다. 모든 입력에 보이는 레이블을 둔다.
- 주요 조작은 44px 이상, 키보드 포커스와 결과 수 안내를 제공한다.
- 첫 화면에서 한 번만 진입 애니메이션을 사용한다. 나머지는 사용자가
  조작한 버튼·테마·필터의 피드백에 집중한다.
- prefers-reduced-motion에서는 이동과 애니메이션을 비활성화한다.
- CSS 토큰으로 두 테마를 함께 관리한다. 운영 상태를 색과 텍스트로 표시한다.

참고: frontend-design 스킬과
https://github.com/nextlevelbuilder/ui-ux-pro-max-skill 의 UI UX Pro Max 스킬.

## 2차 수정: 개인 작업 목록과 동작

검토된 1차 화면에도 홍보성 제목, 설명을 반복하는 질문형 제목, 동일한
테두리 카드와 미니 대시보드 예시가 남아 있었다. 이번 수정은 개인이 만든
아홉 프로젝트라는 실제 내용에 집중한다.

- 기본색을 Cloud #F8F9FB, Paper #FFFFFF, Ink #17243A, Blue #2458D3,
  Slate #526078로 정리한다. 사용자 선택인 밝은 테마와 네이비 다크를 유지한다.
- 자체 호스팅 Pretendard를 유지하고 제목은 48–100px, 본문은 16px/1.75로 쓴다.
  영문 대문자 라벨과 장식용 통계 패널은 사용하지 않는다.
- 첫 화면은 `만든 것들.`이라는 짧은 제목, 실제 프로젝트 종류, 직접 선택하는
  최근 프로젝트 미리보기로 구성한다. 왼쪽 정렬, 1280px 콘텐츠 폭을 유지한다.
- 목록은 바깥 테두리와 반복 버튼이 없는 작품 목록으로 바꾼다. 실제 앱은
  기존 스크린샷을 쓰며, 나머지는 기능별 벡터 그림을 사용한다. 가짜 측정값이나
  가짜 운영 수치는 넣지 않는다.

```text
[jm.]             [프로젝트 / 설치 파일]       [테마 / GitHub]
[만든 것들.]                   [런모니 / Starlink Duo / 여긴얼마?]
[실제 프로젝트 종류]           [선택한 프로젝트 화면 + 상태]
[검색____________________________________] [정렬]
[상태 / 추가 필터]
[제품 그림]             [제품 그림]             [제품 그림]
제목 / 소개 / 실행      제목 / 소개 / 실행      제목 / 소개 / 실행
[Android 설치 파일 목록]
```

UI UX Pro Max의 이번 자동 디자인 추천은 전환 퍼널·FAQ·다크 우선 패턴으로
분류되어 이 요구와 일치하지 않았다. 이를 채택하지 않고 사용자에게 확인된
밝은 화면과 기존 제품 내용을 우선한다. `cleanup` React 검색의 이벤트/타이머
정리 지침과 `interruptible transition` UX 검색의 취소 가능한 전환 지침을 적용한다.

모션은 사용자가 요청한 풍부한 효과를 다음 지점에 분산한다: 제목의 첫 등장,
미리보기 탭·그림 전환, 벡터 경로 그리기, 포인터 기울기, 필터 결과 FLIP 재배치,
섹션 밑줄 그리기, 펼침 메뉴, 테마 크로스페이드, 버튼·링크 조작 피드백.
진행 중인 모션은 새 조작으로 대체할 수 있고, 화면 밖/백그라운드에서는
불필요한 프레임 작업을 하지 않는다. JS가 없으면 콘텐츠는 그대로 보이며,
움직임 줄이기 설정에서는 이동 효과를 끈다. 모션 라이브러리를 추가하지 않고
CSS와 Web Animations API를 사용한다.
