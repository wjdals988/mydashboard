# 프로젝트 탐색 UX 개선

## 벤치마크 (2026-10-14 직접 확인)

- [Raycast Store](https://www.raycast.com/store): 검색, 플랫폼 구분, 설명과 설치 액션의 분리. 적용: 프로젝트 검색, 플랫폼 필터, 별도 APK 다운로드 조건.
- [Vercel Templates](https://vercel.com/templates): 상단 검색과 명시적인 카테고리 필터, 일정한 카드 구조. 적용: 상태·플랫폼 교차 필터, 결과 개수, 검색 결과 없음 및 초기화.
- [Linear Features](https://linear.app/features): 간결한 설명과 제품별 시각 자료 중심의 위계. 적용: 압축된 소개와 최근 업데이트 패널, 프로젝트 목록 우선 배치.

디자인을 복제하거나 제3자 로고·이미지를 가져오지 않았습니다. 기존 프로젝트 미리보기 도식과 프로젝트 데이터는 유지했습니다.

## 변경 내용

- 프로젝트 목록을 다운로드 목록보다 먼저 배치했습니다.
- 최근 프로젝트 3개는 원본의 updatedAt 날짜에서 계산합니다.
- 이름·기능·기술을 검색하고, 상태와 플랫폼 및 APK 유무를 교차 필터링합니다.
- 기본 배열 순서를 유지하며, 최근 업데이트 정렬을 선택할 수 있습니다.
- APK 미공개 Android 프로젝트도 Android 필터에 포함합니다. 플랫폼과 배포 파일 유무를 더 이상 같은 의미로 취급하지 않습니다.
- 카드와 다운로드 목록에 개발 미리보기/서명 릴리스를 표시하고 설치 정보로 연결합니다.
- 모바일에서도 프로젝트·다운로드 탐색 메뉴를 제공합니다.
- 주요 버튼 터치 영역, 본문 보조색 대비, 초점 표시와 reduced-motion 대응을 보강했습니다.

- 기존 전체 npm audit CI의 braces 개발 의존성 경고는 이 UI 변경 범위에서 해결하지 않았습니다.
