# 개인 작업실 스타일 및 모션 수정

첫 개편안에서 홍보성 문구와 반복된 카드 외곽을 덜어내고, 실제 프로젝트를
중심으로 한 개인 작업 목록으로 정리했습니다. 밝은 테마·다크 모드, 기존
프로젝트 정보와 검색 URL 동작은 유지합니다.

## 화면

- 첫 화면 제목을 `만든 것들.`로 줄이고, 실제 프로젝트 종류를 소개합니다.
- 최근 세 프로젝트를 직접 선택하는 미리보기 탭을 추가했습니다. 방향키와
  Home/End로 이동할 수 있고, 자동으로 돌아가는 슬라이드는 없습니다.
- 가상 측정값이 담긴 목록 미니 UI를 제품별 벡터 그림으로 교체했습니다.
  실제 스크린샷이 있는 프로젝트는 원본 앱 화면을 사용합니다.
- 카드 외곽·그림자·기술 태그의 반복을 줄이고, 제목과 소개·실행 링크를 정리했습니다.
- 상세의 앱 그림과 스크린샷 반응도 같은 시각 언어로 맞췄습니다.

## 모션

- 제목 등장, 미리보기 탭 밑줄 이동, 앱 화면/그림 전환, 벡터 경로 그리기.
- 정밀 포인터에서만 최대 3–4도의 기울기와 프로젝트별 그림 반응.
- 필터·정렬 결과의 위치를 이어 주는 FLIP 이동. DOM 위치를 먼저 일괄 읽고
  transform/opacity로 움직입니다. 이전 애니메이션은 새 조작으로 대체합니다.
- 스크롤 진행 표시와 섹션 밑줄 등장, 스크린샷 확대, 링크·버튼 반응.
- 지원 브라우저의 details 펼침/접힘과 테마 크로스페이드.
- 이벤트·ResizeObserver·IntersectionObserver·rAF·Animation을 해제합니다.
  백그라운드 또는 움직임 줄이기 설정에서는 불필요한 작업과 모션을 멈춥니다.
- CSS와 Web Animations API를 사용하며 추가 라이브러리는 없습니다.

## 확인한 내용

- `npm test` 24개, `npm run lint`, `npm run build` 통과.
- Chromium 프로덕션 빌드에서 미리보기 키보드 이동·빠른 연속 전환,
  한국어 검색·플랫폼·설치 파일 필터·최근순 정렬·URL 복귀·빈 결과 복구 확인.
- 필터 적용 직후 실제 위치 애니메이션 실행, 포인터 기울기와 이탈 시 정리,
  벡터 경로 애니메이션, 빠른 테마 변경의 최종 상태와 저장 확인.
- reduced-motion에서 CSS 및 목록 재배치 애니메이션 0개 확인.
- 라이트/다크 각각 320/375/768/1024/1440px 홈에서 가로 넘침 없음.
  전체 상세 페이지도 375/1440px에서 가로 넘침 없음.
- axe-core WCAG A/AA: 홈·런모니·Starlink Duo의 두 테마, 총 6개 화면에서
  전환이 끝난 뒤 검사해 발견된 위반 0건.
- 설치 안내·SHA-256 복사·안전한 목록 복귀, APK 링크와 원본 데이터의 일치 확인.
- 확인한 브라우저 흐름에서 처리되지 않은 JavaScript 오류 없음.
