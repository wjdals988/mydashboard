# 프로젝트 라이브러리 UI 개편

홈을 프로젝트 탐색과 실행/설치에 초점을 둔 구성으로 바꿨습니다. 밝은
블루 테마와 네이비 다크 테마에 공통 색상·간격·모션 토큰을 적용하고,
최근 프로젝트의 실제 화면을 소개합니다. 기존 프로젝트 순서, APK URL,
버전, 해시와 릴리스 정보는 유지합니다.

- 카드의 주 동작은 웹 서비스 실행 또는 앱 다운로드이며, 상세 보기는 보조 동작입니다.
- 검색·상태·플랫폼·설치 가능 여부·정렬 조건은 URL로 공유할 수 있습니다.
  카드에서 상세 페이지로 갔다가 목록으로 돌아오면 조건을 복원합니다.
- 입력은 즉시 반영하고 URL 변경은 별도로 동기화하여 체크박스와 한국어 입력이
  라우터 갱신 시점에 영향을 받지 않게 했습니다.
- Android/안드로이드 검색은 프로젝트의 실제 플랫폼 분류도 참조합니다.
- 상세에 섹션 바로가기를 추가하고, 설치 절차와 기술 검증 정보를 구분했습니다.
  해시 복사는 성공·실패를 안내하며 반복 실행과 타이머 정리를 처리합니다.
- 첫 화면 진입과 사용자 조작에 짧은 애니메이션을 적용했습니다.
  움직임 줄이기 설정에서는 이동 애니메이션을 끕니다.

## 검증

- `npm test`: 24개 통과. 플랫폼 검색의 한글/영문 별칭 회귀 테스트 추가.
- `npm run lint`, `npm run build`: 통과. 기존 정적 페이지 생성 유지.
- `npm audit --audit-level=high`: 통과. 기존 의존성의 moderate 권고 8건은 남아 있으며
  이번 변경은 의존성을 추가하거나 변경하지 않습니다.
- Chromium 프로덕션 빌드: 검색 → 상태 선택 → 상세 → 조건 유지 목록 복귀,
  새로고침 복원, 빈 결과 복구, 플랫폼/설치 가능 필터와 최근순 정렬 확인.
- 라이트/다크 선택 및 저장, reduced-motion, 설치 정보 펼치기,
  SHA-256 클립보드 복사, 외부 URL을 통한 목록 복귀 차단 확인.
- 홈 320/375/768/1024/1440px 및 전체 프로젝트 상세 375/1440px에서 가로 넘침 없음.
- axe-core 4.10.3 WCAG A/AA 검사: 홈 라이트·다크, 런모니·Starlink Duo
  상세 라이트에서 발견된 위반 0건. 자동 검사는 수동 접근성 검토 전체를 대체하지 않습니다.
- 다운로드 영역의 모든 APK 링크가 `projects.json`과 일치함을 확인했습니다.

디자인 방향은 [프로젝트 라이브러리 디자인](../design/project-library.md)을 참조하세요.
